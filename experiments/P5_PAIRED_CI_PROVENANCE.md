# Provenance: two generations of P@5 paired-CI artifacts (2026-10-24)

The repository retains **two generations** of strict-GT localization scoring.
This note explains which one corresponds to the submitted ICMLC 2027 paper's
Table 1, so that readers do not mix them.

## Current (paper) source

- **`final_gt_eval.json`** (2026-10-10): production CNN pipeline, validation-selected
  λ_rule = 1.0, seeds 123/456/789, strict GT (202 gold-positive emails).
  Sparse ABMIL P@5 per seed = 0.479 / 0.475 / 0.486 → **0.480 ± 0.005**.
- **`main_table_data.json`** (generated by `scripts/m_table_data.py`): authoritative
  paired per-email bootstrap CIs (5,000 resamples, n = 202) for Table 1.
  The reference "ours" is the seed-averaged per-email ranking; table cells print
  per-seed means ± std from `final_gt_eval.json`.
  P@5 differences (row minus ours; a CI excluding zero gives a table star):

  | Row | Δ P@5 | 95% CI | detectable |
|---|---|---|---|
  | ABMIL (CNN) | −0.020 | [−0.034, −0.007] | yes (ours better) |
  | AI2TALE | −0.002 | [−0.017, +0.013] | no |
  | BERT-ABMIL | −0.004 | [−0.024, +0.016] | no |
  | Rules-only | +0.025 | [+0.008, +0.042] | yes (scorer better) |
  | Snorkel | +0.020 | [+0.002, +0.039] | yes (scorer better) |
  | Sparse BERT (August single run) | +0.025 | [+0.009, +0.042] | yes (scorer better) |

## Retired (kept for traceability only)

- **`gt_scores.json`** (2026-09-17) and **`m7_p5_paired_ci.json`**
  (script `scripts/m7_p5_paired_ci.py`, run 2026-10-11 against that 9/17
  cache): the earlier scoring generation. Its
  Sparse CNN pseudo-model is the λ_rule = 3.0, seed-42 run (P@1 0.6485 on that
  cache — see `sparse_bert/PROVENANCE_lambda.md` for the same operating-point
  issue on the BERT side), with P@5 0.497 ± 0.002. Its paired P@5 CIs
  (AI2TALE and BERT-ABMIL starred; Rules-only/Snorkel not) are artifacts of
  that superseded scoring set and must not be used with the current table.
- `gt_localization_results_strict.json` (9/17) is the matching full snapshot;
  its **BERT rows remain current** (the August single-run BERT endpoints were
  never rescored), while its CNN Sparse row is superseded by `final_gt_eval.json`.

No model was retrained when correcting the paper's P@5 cell; only the printed
number, its stars, and the accompanying sentence were aligned to the existing
frozen 10/10 artifacts.
