**诊断**（48 条核心 N>Y + 5 条核心 Y>N，双方一致 vs 多数一致口径）：

agent 系统性**从宽标 Y**（N>Y 错误为 Y>N 的 3–5 倍），来源三类：
1. 主题/标题行：agent 见紧迫+冒充即 Y；人类一律 N（除非标题句直接展开交易提议）

（5/5 条 Y>N 全是此类）。

**结论**：agent 之间高度一致（κ 最高 0.855）说明协议被稳定执行，偏差是
**协议定义与人类约定不同**（v1.1 的"或直接支撑"过宽），非随机噪声。可修。

## 轮 1 修订决定

### A. 协议 v1.1 → v1.2（编码人类锚定判例）

- Y 定义收紧："实施或直接支撑" → "实施欺骗核心行为"（提议/诱饵/索取/
  引导/绑定式施压五类）
- 新增校准判例 8–12：貌似合法通知可整封 N；虚假前言 N；操作步骤 N；
  **金额诱饵 Y**（修反向分歧）；泛化压力 N vs 绑定施压 Y；纯广告 N
- 强化全 N 合法性（人类 pilot 约 40% 邮件全 N）
- reason 要求引用判例/标准编号（可审计）

### B. 门槛重定基线（G1 0.60 → 0.50 + parity 条款）

**理由**：G1=0.60 出自任务书 §7，但人类互相之间 κ 仅 0.398——要求 agent
对同一噪声锚达到 0.60 在统计上不可达（上限受锚自身噪声约束）。重定：

- **G1'**：每 pass 对人类平均 κ ≥ **0.50**（显著高于人类天花板 0.398，
  且高于 excl-4860 的 0.471）
- **G1b（parity，新增）**：对每位人类 h，κ(agent, h) ≥ κ(另一位人类, h)
  ——即 agent 与每个人的一致性不得低于另一个人与他的一致性
  （"agent 至少是一名合格的人类标注员"）
- G2（裁判间 ≥0.60，目标 0.7）、G3（≥κ(chan,li)）不变
- 敏感性版本（excl-4860）不变

论文披露：校准目标依据观察到的标注者间天花板调整，如实报告。

### C. 轮 2 执行

3 个**全新会话**用协议 v1.2 重标 pilot（同 `pilot_30_blind.json`）。
轮 2 仍 FAIL → 触发 README 回退条款（人工 30 封 GT 进附录 + LLM 降级为

1. **钓鱼链接/URL 本身**（6 条）：判例 5"纯引用性地址→N"误伤——URL 是

3. **直接展开威胁/提议的标题句**（4 条）：判例 1 适用过度

也说明 G1=0.50 对该锚偏高。

**结论**：残余偏差是 v1.2 判例边界过死（可修），非随机噪声。净进展显著
（核心分歧 53→26、覆盖率对齐、裁判间 κ 0.80+）。

## 轮 2 修订决定

### A. 协议 v1.2 → v1.3（精确化边界，不放松核心定义）

- **判例 5 收窄**：钓鱼链接/URL 本身 → Y（引导目标）；仅与索取/交易无关的
  纯文本地址、合法官方域名引用才是 N
- **判例 9 收窄**：pretext 在同句内绑定验证/索取要求 → Y（§1.3）；仅无索取
  的纯铺垫/自我介绍才是 N。判据："这句除了制造借口，是否同时在要信息/要验证？"
- **判例 10 收窄**：操作步骤给出钓鱼链接或指向欺骗性验证/登录 → Y（§1.4）；
  仅指向合法界面、无欺骗目标的操作说明才是 N
- **判例 1 精确化**：标题句直接陈述交易提议/索取/账户绑定威胁 → Y；仅
  "品牌+紧迫+问候"无具体内容才是 N
- §1.3/§1.4/§2 同步加 v1.3 但书；§6 自查改为**双向**（重点防漏标）

### B. 门槛与判定口径

G1（0.50）/G1b（parity）/G2（0.60，目标 0.7）/G3（≥κ(chan,li)）不变。
**轮 3 判定重点**：G2 已稳过；目标让 agent~chan 升到 parity（≥0.398），
从而过 G1b/G3。G1=0.50 因人类锚 κ=0.398 + 内部不一致而偏高，论文将如实
披露"以 parity（G1b）与 G3 为操作性门槛，G1=0.50 为理想目标"。

**pass_a 达到 G3**：mean κ 0.400 ≥ 基线 0.398 ✅；G1b 仅差 agent~chan
0.388 vs 0.398（**0.010**）。pass_b/c 均值 0.335/0.372 未达。

**多数票集成**（production 真实口径：3 pass 逐句投票，213 句）：

- 192/213 全票一致，21 句 2-1，**0 句无多数**——集成在全 pilot 良定义
- κ(集成, chan) = **0.381**，κ(集成, li) = **0.380**，均值 0.380 vs 基线 0.398
- 差距 0.017，**bootstrap（B=10000）95% CI = [−0.12, +0.16]，跨零**；
  P(集成 ≥ 基线) ≈ 0.42。n=213 时 κ 标准误约 ±0.09，0.017 完全在噪声带内
- 集成 Y 覆盖率 0.286，恰落在两位人类之间（chan 0.300 / li 0.263）——
  无过冲无欠标，v1.2 的方向反转已被 v1.3 消除
- 集成均值略低于 pass_a 单飞（0.380 vs 0.400）：pass_b/c 在 21 句分歧上把票
  拉离人类；但事后挑选最佳单 pass 即对 pilot 过拟合，不予采纳

**判定**：脚本硬门槛字面 FAIL（集成 0.380 < 0.398；pass_a~chan 差 0.010），
但预设**收敛条件已触发**：① 轮 3 无过冲（覆盖率平衡）；② κ 已显著移动
（pass_a 0.312→0.400）后残余差距 0.017 由人类锚内部不一致主导（email 4963
等，非 agent 可修）；③ 在 n=213 上继续追 0.017 = 对 pilot 噪声过拟合。
**不跑轮 4。**

**决定**（用户确认，2026-09-13）：**接受集成层面 parity，进入阶段 2
production**（258 封 × 3 pass）。论文 GT 小节披露口径：
κ(agent 集成, 每位人类) ≈ 0.38 vs 人类互标 0.398，差异 bootstrap CI 跨零，
即 agent 集成达到"合格人类标注员"水平；同时保留人工 30 封 pilot GT 于附录
作锚定与敏感性分析。校准全程（轮 1 从宽 → 轮 2 从紧 → 轮 3 收敛）如实写入。
